# multilink-samthink

Link-in-bio / mini portfolio de samthink. Next.js 16 + Tailwind 4, exportado como página estática.

- Proyectos y redes: `src/lib/links.ts`
- Fondo ASCII interactivo (canvas, ondas azules al hacer click): `src/components/ascii-field.tsx`

```bash
npm install
npm run dev
```

Despliegue: importar el repo en Vercel (framework Next.js, sin configuración extra).
